# 企业AI搜索可见度测试（静态版）

纯前端、零后端依赖的 GEO 诊断问卷 + 结果页。

## 特性
- `index.html` 单文件自包含：算分逻辑（原 `server.py` 的 `calc_score`）已用 JS 复刻并内联，用户浏览器内完成「填问卷 → 出分 → 看短板」，不依赖任何服务器。
- 5 大模块合计 100 分：企业实体信息(20) / 产品信息(25) / 内容资产(20) / AI可理解性(20) / AI搜索验证(15)。
- 部署到任意静态托管（GitHub Pages / Vercel / Netlify / COS）即可，永不依赖 Python 进程，不会被沙箱冻结。
- 结果页「保存我的测试结果到企业档案」需接入飞书表单公开链接（在 `index.html` 内 `FEISHU_FORM_URL` 处填入）；未填时自动走「复制结果」兜底。

## 本地预览
直接用浏览器打开 `index.html` 即可，无需启动服务。

## 部署（GitHub Pages）
1. 推到 GitHub 仓库（根目录放 `index.html`）。
2. 仓库 Settings → Pages → Source 选 `main` 分支 `/root`。
3. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

## 算分口径
每题 1–5 分；全 1 分 = 20，全 3 分 = 60，全 5 分 = 100。
等级：0–40 薄弱 / 41–60 待提升 / 61–80 良好 / 81–100 优秀。
